# KYC Assistant App

Full product development lifecycle for a FinTech compliance application - from stakeholder discovery through to UML design, agile sprint delivery, and a live deployed prototype. The app automates KYC data extraction from UK Companies House, addressing the manual, time-consuming processes that cost UK financial institutions an estimated £38.3bn in financial crime compliance annually.

## Key features

- Automated company data extraction via Companies House API
- Portfolio management for saving and monitoring companies
- Audit history trail for compliance tracking
- Red flag detection based on Companies House data
- Export functionality (PDF/Excel)

## Methodology

- Requirements gathered via stakeholder interviews with KYC analysts, team leads, and compliance directors
- Prioritised using RICE scoring framework
- Delivered across three one-week sprints using Scrum methodology
- UML diagrams: use case, class, and sequence diagrams
- Frontend prototype built in UX Pilot with backend deployed on PythonAnywhere
